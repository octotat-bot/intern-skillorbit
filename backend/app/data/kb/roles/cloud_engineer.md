<!-- chunk id=jd-cloud-001 | title=Cloud engineer: typical responsibilities | topic=job-description | roles=cloud_engineer | sections=experience,projects | source=self-authored -->
Junior cloud engineers provision and operate infrastructure on AWS, Azure or Google Cloud, containerize services, maintain CI/CD pipelines, write automation scripts, manage access and networking, and monitor systems for availability and cost. Postings often mention on-call support, incident response and documentation.

<!-- chunk id=jd-cloud-002 | title=Cloud engineer: required skills | topic=job-description | roles=cloud_engineer | sections=skills | source=self-authored -->
Commonly required: hands-on experience with at least one major cloud platform, Linux administration, Docker, Kubernetes, CI/CD (GitHub Actions, Jenkins or GitLab CI), infrastructure as code (Terraform or CloudFormation), networking fundamentals (VPCs, DNS, load balancers) and scripting in Python or Bash. Frequently preferred: monitoring with Prometheus and Grafana, serverless functions, IAM and security basics, and Helm.

<!-- chunk id=jd-cloud-003 | title=Cloud engineer: why IaC and Kubernetes matter | topic=skill-gap | roles=cloud_engineer | sections=skills | source=self-authored -->
Infrastructure as code is expected because teams need reproducible, reviewable environments instead of manual console changes; Terraform is the most widely listed tool. Kubernetes is the standard way to run containers at scale, so employers look for experience deploying and debugging workloads on a cluster, even a local one such as minikube or kind.

<!-- chunk id=jd-cloud-004 | title=Cloud engineer: portfolio project ideas | topic=projects | roles=cloud_engineer | sections=projects | source=self-authored -->
Good cloud portfolio projects are reproducible from a repository: Terraform that provisions a VPC, a load balancer and an autoscaling group; a GitHub Actions pipeline that tests, builds a Docker image and deploys to Kubernetes; a serverless API with monitoring and alerts; or a cost-optimization write-up. Include architecture diagrams and teardown instructions.

<!-- chunk id=jd-cloud-005 | title=Cloud engineer: example strong bullets | topic=bullets | roles=cloud_engineer | sections=projects,experience | source=self-authored -->
Examples of cloud bullets: "Provisioned a 3-tier AWS environment with Terraform, reducing setup time from 2 days to 20 minutes." "Built a GitHub Actions pipeline that tests, containerizes and deploys to Kubernetes on every merge." "Cut monthly cloud spend by 30% by rightsizing EC2 instances and adding S3 lifecycle rules."
