<!-- chunk id=jd-web-001 | title=Web developer: typical responsibilities | topic=job-description | roles=web_developer | sections=experience,projects | source=self-authored -->
Junior web developers build and maintain pages and components, convert designs from Figma into responsive layouts, integrate REST APIs, fix cross-browser bugs, and improve performance, accessibility and SEO. Postings often mention code reviews, Git workflows and working closely with designers.

<!-- chunk id=jd-web-002 | title=Web developer: required skills | topic=job-description | roles=web_developer | sections=skills | source=self-authored -->
Commonly required: semantic HTML, modern CSS (Flexbox, Grid, media queries), JavaScript (ES6+), a frontend framework such as React, Angular or Vue, responsive design, Git, and consuming REST APIs. Frequently preferred: TypeScript, Tailwind CSS or Sass, Next.js, testing with Jest, accessibility (WCAG), SEO basics, and build tools such as Vite or Webpack.

<!-- chunk id=jd-web-003 | title=Web developer: why responsive design and accessibility matter | topic=skill-gap | roles=web_developer | sections=skills | source=self-authored -->
Most web traffic is on mobile devices, so employers expect layouts that adapt to any screen size; "responsive design" is a standard screening term. Accessibility is increasingly required by law and by company policy: semantic HTML, keyboard navigation, alt text and sufficient color contrast. Mentioning both, and showing them in a project, signals production-ready frontend skills.

<!-- chunk id=jd-web-004 | title=Web developer: portfolio project ideas | topic=projects | roles=web_developer | sections=projects | source=self-authored -->
Good web portfolio projects are deployed and measurable: a responsive React app consuming a public API with loading and error states, a personal portfolio scoring 95+ on Lighthouse, an accessible form-heavy app tested with a screen reader, or a clone of a real site's key flow with your own improvements. Link the live URL and the repository.

<!-- chunk id=jd-web-005 | title=Web developer: example strong bullets | topic=bullets | roles=web_developer | sections=projects,experience | source=self-authored -->
Examples of web bullets: "Built a responsive React dashboard consuming 3 REST APIs, with skeleton loading and error states." "Reduced bundle size by 35% by code-splitting routes with Vite." "Raised the Lighthouse accessibility score from 72 to 98 by fixing contrast, labels and keyboard focus."
